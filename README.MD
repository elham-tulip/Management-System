## Management System

A full-stack Management System built with backend and front. The application provides authentication, role-based access, member management, attendance management, and a dashboard for viewing management statistics.

### Technologys

## Frontend

- React
- vite
- React Router
- Axios
- Tailwind Css
- Lucide React
  ## Backend
- Node.js
- Express.js
- MongoDb
- JWT Authentication
- bcrypt

  ## Features

Authentication

- User signup
- User login
- JWT authentication
- protected routes
- Logout
- password hashing with bcrypt
- role-based authorization

### User Roles

the system supports three roles: ## Admin - Dashboared - Manage member - Manage Attendance - manage setting - Add, edit , and delete memebers ## Supervisor - Dashboard - View members - Manage attendance

## User - Dashboard - View member

       ## Member Management

## Admins can:

     Add members
     View all members
     Edit member information
     Delete members

- Member information includes:

      Name
      Email
      Division
      Year
      Attendance

The system stores attendance records for members.

# Attendance statuses include:

- Present
- Absent

## Dashboard

The dashboard provides management statistics such as:

- Total Members
- Total Divisions
- Attendance Rate
- Upcoming Sessions
- Attendance information
